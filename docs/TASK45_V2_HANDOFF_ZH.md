# Task 4-5 整合说明

V2 已完成，Task 1-3 和 V1 原始证据均保留。最新版入口是仓库根目录
`README_TASK45_V2.md`，运行函数为 `run_task45_v2`，独立复核函数为
`verify_task45_v2`。原来的 `run_task45` 继续对应旧版，整合时请使用带 `_v2` 的入口。

正式实验使用冻结后的全新种子 5200-5209，共 50 次：两场景的 Task 4
20/20 成功，带投影的 Task 5 20/20 成功，主场景仅姿态罚项消融 0/10。
消融的 10 次失败全部保留：10 次姿态超限，其中 1 次还未达到保守间距。
50 次正式运行均没有自碰撞失败。以上是有限种子集上的结果。

旧版 Task 5 的 0/20 来自自碰撞：直立方向和障碍间距原本都合格，
但原优化代价没有自碰撞项，姿态投影也不能处理连杆几何。
V2 对两任务同时加入自碰撞代价、候选实际网格筛选和可行候选优先接受，
并避免相邻实验复用重启种子。Task 5 保留原姿态罚项与 PoE 方向投影。

Task 5 正式路径最差最大倾角为 2.35°，最低保守间距为 41.12 mm。
验收门槛仍是 5°、35 mm、实际障碍碰撞和自碰撞均为零。
验证属于每关节步长不超过 0.0125 rad 的离散加密检查。

独立复核通过全部 50 条正式轨迹，并完整回放 1991 轮随机采样和接受更新。

已完整解码。动画表示归一化路径进度，没有执行时间或动力学含义。
